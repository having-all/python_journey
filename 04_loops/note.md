# 반복문 - for, while
> 같은 작업을 데이터 하나씩 자동으로 반복하기 위함이다. 

**학습 목표**
- for문으로 리스트, 딕셔너리, range를 순회할 수 있다.
- enumerate() 와 zip()을 상황에 맞게 쓸 수 있다.
- while 문과 break, continue로 반복을 제어할 수 있다.
- 리스트 컴프리헨션으로 데이터를 한 줄에 변환, 필터링 할 수 있다.

## 4-1. for문 기본
> 리스트에서 값을 하나씩 꺼내 변수에 담고, 들여쓴 코드를 실행한다. 더 꺼낼 값이 없으면 끝난다. 변수 이름은 리스트 이름의 단수형으로 짓는 것이 관행이다. (예: medications -> med)

## 4-2. range(), enumerate(), zip()

| 함수 | 역할 | 예시 |
|---|---|---|
| range(끝) | 0부터 끝-1까지 | range(5) -> 0, 1, 2, 3, 4 |
| range(시작, 끝) | 시작부터 끝-1까지 | range(1, 6) -> 1, 2, 3, 4, 5 |
| enumerate(리스트, 1) | 번호와 값을 함께 | 대기 1번, 2번 ... |
| zip(리스트1, 리스트2) | 같은 순서의 값을 짝지어 | 이름과 약물을 함께 |

## 4-3. 딕셔너리 순회

| 방법 | 꺼내는 것 | 
|---|---|
| for key in d: | 키 |
| for value in d.values(): | 값 |
| for key, value in d.items(): | 키와 값(가장 많이 사용) |

## 4-4 반복문의 3가지 패턴
> "나는 지금 어떤 결과가 필요한가?"를 먼저 정하면 패턴이 정하기 쉬워진다

| 패턴 | 필요한 결과 | 반복문 밖에서 준비할 것 | 핵심 동작 |
|---|---|---|---|---|
| 조건처리 | 화면 출력, 알림 | 없음 | if + print |
| 누적 | 숫자 하나(개수, 합계) | count = 0, total = 0 | +=, -+ |
| 모으기 | 새 리스트 | result = [] | .append () |

# 4-5. while 문
> 조건이 참인 동안 계속 반복한다. **반복 횟수를 알면 for, 언제 끝날지 모르면 while**을 쓴다. 조건이 거짓이 되지 않으면 무한 반복에 빠지므로(Ctrl+C로 중단), 최대 횟수 같은 안전장치를 둔다.

## 4-6. break와 continue
- break: 반복문을 **완전히 종료**한다. 위험 수치를 발견하면 즉시 멈출 때
- continue: 이번 회차만 **건너뛰고** 다음 회차로 간다. 측정 오류값을 무시할 때

## 4-7. 리스트 컴프리헨션
- "새 리스트에 모으기" 패턴을 한 줄로 줄인 문법
- [만들 값 for 변수 in 리스트 if 조건]으로 읽는다
- 복잡한 로직은 일반 for 문이 더 읽기 쉽다

## 자주 하는 실수
- 누적 변수를 만들지 않고 += -> NameError 발생. total = 0, result = ' ' 을 반복문 위에 먼저 쓴다
- 숫자 1과 i 혼동 -> total += 1은 매번 1을 더하고, total += i는 현재 값을 더한다
- 글자를 꺼낼 때 소괄호 사용 -> text(0)은 TypeError:'str' object is not callable. 인덱싱은 대괄호 text[0]
- print를 반복문 안에 둔 채 최종 결과만 기대함 -> 중간 과정이 매번 출력된다. 결과만 보려면 들여쓰기를 빼서 반복문 밖으로 꺼내 써야 함
- sum 같은 내장 함수 이름을 변수로 쓸 경우 -> 이후 sum() 함수를 사용할 때 에러 발생. total, result 등의 다른 이름을 사용
- while에서 조건 변수를 바꾸지 않은 -> 무한 반복

# 2장. 자료구조 - List, Tuple, Dictionary, Set
> 여러 데이터를 이름 하나로 묶어 관리하는 법을 배운다. 환자 100명의 체온도 변수 100개가 아니라 리스트 하나에 담는다.

**학습 목표**
- 4가지 자료구조의 특징과 차이를 설명하고 상황에 맞게 고를 수 있다
- 인덱싱과 슬라이싱으로 원하는 데이터를 꺼낼 수 있다
- 메서드로 데이터를 추가·수정·삭제할 수 있다
- 딕셔너리 리스트로 여러 환자의 정보를 관리할 수 있다.

## 2-1. 4가지 자료구조 한눈에 보기

| 자료구조 | 기호 | 순서 | 중복 | 변경 | 언제 쓰나 |
|---|---|---|---|---|---|
| 리스트(List) | [ ] | 있음 | 허용 | 가능 | 시간순 체온·혈압 기록, 처방 목록 |
| 튜플(Tuple) | ( ) | 있음 | 허용 | 불가 | 정상 범위 같은 고정 기준값 |
| 딕셔너리 (dictionary) | {key : value} | 있음 | key는 불가 | 가능 | 이름표가 붙은 환자 차트 |
| 집합 (set) | { } | 없음 | 불가 | 가능 | 중복 제거, 알레르기 충돌 확인 |

## 2-2. Indexing, Slicing
> 인덱스는 **0부터** 시작하고, 음수는 뒤에서부터 센다(마지막 : -1). 슬라이싱 [시작:끝]은 **끝 번호를 포함하지 않는다**.

## 2-3. List Method
| 하고 싶은 일 | Method | 예시 |
|---|---|---|
| 맨 끝에 1개 추가 | append(값) | bp.append(135): bp 리스트 맨 끝에 값 추가 |
| 특정 위치에 삽입 | insert(위치, 값) | bp.insert(1, 122): bp 리스트 2번째(인덱스: 1)에 값(122) 추가 |
| 여러 개 한꺼번에 추가 | extend(list) | bp.extemd([128, 119]): bp 리스트에 [128, 119] 리스트 추가 |
| 값으로 삭제 | remove(값) | meds.remove("임시처방약"): meds 리스트에서 "임시처방약" 값 제거 |
| 위치로 꺼내며 삭제 | pop(위치) | meds.pop(3): meds 리스트의 4번째 값(인덱스: 3) 삭제, meds.pop(): 아무 값도 없으면 마지막 값 |
| 위치, 개수 찾기 | index(값), count(값) | names.count("이영희"): names 리스트에서 "이영희"가 몇명인지 찾는 것 |
| 정렬(원본 유지) | sorted(리스트) | sorted(w, reverse=True): w 리스트를 내림차순 정렬, reverse=False이면 오름차순 정렬 |
| 정렬(원본 변경) | 리스트.sort() | w.sort() : w 리스트를 정렬, sort() 비어 있으면 오름차순 |
| 문자열로 잇기 | "구분자".join(리스트) | ".".join(meds): .으로 문자열 잇기 |

## 2-4. Tuple : 바뀌면 안되는 값
> 튜플은 한 번 만들면 수정할 수 없다. 정상 범위 같은 기준값을 실수로 바꾸는 사고를 막아준다.

## 2-5. Dictionary: 이름표로 찾는 데이터
> {키: 값} 형태로 저장하고 딕셔너리[키]로 꺼낸다. 없는 키에 대입하면 추가, 있는 키에 대입하면 수정된다.
> 딕셔너리는 인덱싱, 슬라이싱이 안됨. key로 호출

> **중첩 구조**: 딕셔너리 안에 딕셔너리, 리스트를 넣을 수 있고, 키를 이어 붙여 꺼낸다.

## 2-6. 집합: 중복 제거와 비교
> 집합은 중복을 자동으로 없애고, 두 집합의 공통점, 차이점을 기호 하나로 계산한다.

| 연산 | 기호 | 의미 |
|---|---|---|
| 합집합 | A | B | 둘 중 어디든 있는 것 |
| 교집합 | A & B | 둘 다에 있는 것 |
| 차집합 | A - B | A에만 있는 것 |
| 대칭차집합 | A ^ B | 한쪽에만 있는 것 |

> **자료 구조 변환**: list(), tuple(), set(), dict()로 서로 바꿀 수 있다. 중복 제거 후 정렬은 sorted(set(리스트))가 자주 쓰인다.


## 자주 하는 실수
- 인덱스를 1부터 셈  → 첫 번째는 [0], 마지막은 [-1]입니다. 범위를 넘으면 IndexError.
- 슬라이싱은 끝 번호를 포함한다고 생각함 → [2:5]는 인덱스 2, 3, 4이다.
- append와 extend 혼동 → 여러 개를 하나씩 넣으려면 extend
- 없는 키를 dict[키]로 꺼냄 → keyError. 확실하지 않으면 get()을 쓴다.

# 3장. 조건문 if, elif, else
> 데이터에 판단 로직을 붙이는 법을 학습. "체온이 37.5℃ 이상이면 발열"처럼 임상에서 쓰이는 판정 기준을 그대로 코드로 옮길 수 있다.

**학습 목표**
- if/if-else/if-elif-else의 흐름을 설명하고 작성할 수 있다
- 범위 비교, in, and, or, not으로 복합 조건을 만들 수 있다.
- 딕셔너리, 집합 같은 자료구조와 조건문을 결합할 수 있다.
- 간단한 분기는 삼항 연산자로 한 줄에 쓸 수 있다.

## 3-1. 기본 문법
> 조건 끝에는 반드시 콜론(:)을 붙이고, 실행할 코드는 스페이스 4칸을 들여쓴다. 들여쓴 부분이 하나의 블록이고, 들여쓰기가 끝나면 블록도 끝난다.

## 3-2. 조건을 만드는 도구들

| 도구 | 예시 | 뜻 |
|---|---|---|
| 범위 비교 | 90 <= bp <= 139 | 90이상 139이하 |
| in / not in | "발열" in symptoms | 리스트·집합·문자열 안에 있는가? |
| and | age >= 65 and bp >= 140 | 65세 이상, 혈압 140이상: 둘 다 True |
| or | chest_pain or spo2_low | 흉통, 산소포화도 저하: 둘 중 하나 True |
| not | not is_pregnant | 참, 거짓 반전 |
| is None | patient_id is None | 값이 비어 있는가? |

# 1장. 변수와 데이터 타입
> 데이터를 이름표 붙은 상자(변수)에 담고, 종류(타입)에 맞게 계산하고 출력하는 법을 배웁니다.

**학습 목표**
- print() 와 f-string으로 원하는 형식의 문장을 출력할 수 있다.
- 명명 규칙에 맞는 변수를 만들고 값을 바꿀 수 있다.
- int, float, str, bool을 구분하고 type()으로 확인할 수 있다.
- • 산술·복합 대입·비교·논리 연산자로 의료 수치를 계산하고 판정할 수 있다.

## 1-1. print(): 화면에 출력하기
> 괄호 안의 값을 화면에 보여준다. 쉼표로 여러 값을 넘기면서 사이에 공백이 자동으로 들어간다.

## 1-2. 변수 - 이름표 붙은 상자
> "="는 "같다"가 아니라 **오른쪽 값을 왼쪽 상자에 넣는다**는 뜻이다. 숫자를 변수에 담아두면, 값이 바뀔때 한 곳만 고치면 된다.
> f-string은 변수를 문장 안에 끼워 넣는 깔끔한 출력

## 1-3. 변수 이름 규칙
| 규칙 | 올바른 예 | 잘못된 예 |
|---|---|---|
| 영문자, 숫자, 언더바'_'만 사용 | patient_name | patient-name, patient@id |
| 숫자로 시작할 수 없음 | patient_1, second_dose | 1st_patient, 2nd_dose |
| 대문자와 소문자는 다른 변수 | Name과 name은 별개의 변수 | |
| 예약어(if, for, def 등)는 사용 불가 | for_count | for = 10 |
| 공백 불가 | patient_name | patient name |

> 파이썬은 단어를 밑줄로 잇는 **snake_case**를 권장한다. a, x철럼 뜻을 알 수 없는 이름보다 systolic_bp, is_hospitalized 처럼 뜻이 보이는 이름을 사용. 한글 변수명도 가능하지면 영문명을 권장

## 1-4. 데이터 타입
| 타입 | 이름 | 예시 | 의료 데이터 예 |
|---|---|---|---|---|
| int | 정수 | 25, -10, 0 | 심박수, 혈당, 나이 |
| float | 실수 | 36.5, 172.4 | 체온, 키, 체중, BMI |
| str | 문자열 | "홍길동", "A" | 이름, 진단명, 진료과 |
| bool | 불린 | True, False | 발열 여부, 당뇨 여부, 고혈압 여부 |

## 1-5. 연산자
| 종류 | 연산자 | 
|---|---|
| 산술 | 사칙연산: +, -, *, / | 
| 산술 | //: 몫, %: 나머지, **: 거듭제곱 |
| 복합 대입 | +=: 값을 더해줌, -=: 값을 빼줌, *=: 값을 곱해줌, **=: 거듭제곱해줌 |
| 비교(결과는 항상 bool) | >, <, >=: 이상, <=: 이하, ==: 같다, !=: 같지 않다 |
| 논리 | and: 교집합(둘다 참), or: 합집합(하나라도 참), not: 아닌 것(반전) |

> 자주하는 실수
- "=", "==" 다르다
- 문자열과 숫자를 +로 이음 -> "나이:" + 45 는 오류 => f-string 사용 권유

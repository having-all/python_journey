
# 기본 데이터 타입

# 1. 정수
- int: -2, -1, 0, 1, 2

# 2. 실수
- float: 0.1, 0.5, 3.14

# 3. 불리언
- boolean: True, False로 
- 예시) a = 10 if a = 20 => False

# 4. 문자열
- str
- 여러 개의 문자를 나열한 것
- 작은 따옴표('') 혹은 (" ") 사이에 문자를 넣어서 생성
- """ 문장 여러줄 """ 사용 가능
- 이스케이프 문자 (escape string) : 문자열 내 특정 효과를 주는 것 (\n, \t, \b)

# 1. 산술연산자
| 기호 | 의미 |
|---|---|
| +, -, *, / | 사칙연산 |
| // | 몫 |
| % | 나머지 |
| ** | 지수(거듭제곱, 승) |

# 2. 대입연산자(assignment operator)
- =: 왼쪽 변수에 오른쪽 값을 할당하는것 
  ex) a = 10
    - 변수에 새로운 값을 입력하면 기존 값은 없어짐(대체)
    - 변수의 대입은 오른쪽에서 왼쪽으로 진행됨
        - num1 = num2 = num3 = 100 : 모두 100의 값을 가짐
    - 대입 연산자의 왼쪽에는 변수만 올 수 있음
    - 대입 연산자의 오른쪽에서 상수, 변수 등이 위치
    - 대입 연산자와 산술 연산자를 함축할 수 있음
        - a += 3은 a = a+ 3과 동일
        - +=, -=, /=, %=, **=

# 3. 비교 연산자 (comparison operator)

| 기호 | 의미 |
|---|---|
| == | 같다 |
| != | 다르다 |
| > | 크다 |
| < | 작다|
| >= | 크거나 같다|
| <= | 작거나 같다|

# 4. 논리 연산자 (logical operator)

| 기호 | 의미 |
|---|---|
| & | and (교집합) |
| | | or (합집합) |

# 5. 연산자 우선순위
- 일반적인 수학의 연산자 우선순위와 동일
- 강제로 연산을 선수하려면 괄호를 사용
